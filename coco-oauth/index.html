COCO

사용자가 자신의 Mac에서 운영하는 개인 업무 비서입니다.

사용자가 연결하고 접근을 허용한 메일, 일정, 할 일을 바탕으로 필요한 자료를 찾고, 초안을 준비하고, 맡긴 작업의 진행과 결과를 확인합니다.

계정 연결이 필요한 이유

  • 메일 계정: 사용자가 요청한 메시지 검색·조회와 회신 초안 준비
  • 일정·할 일: 본인의 일정과 후속 작업 확인 및 요청한 등록·변경
  • 업무 메시지: 허용된 대화의 검색·조회와 요청한 답변 준비

메일이나 메시지의 실제 전송은 해당 전송에 대한 사용자 요청 또는 승인 범위에서 실행합니다.

이 페이지는 앱 소개와 데이터 처리 안내를 위한 페이지입니다. 계정 비밀번호, OAuth 토큰 또는 메일 내용을 입력받지 않습니다. 연결은 Mac의 COCO와 해당 서비스의 인증 화면에서 진행합니다.

개인 운영

COCO는 운영자 본인의 계정과 업무를 위한 도구이며, 이 웹페이지에서 일반 회원을 모집하거나 공개 서비스를 판매하지 않습니다.
