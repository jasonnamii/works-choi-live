개인정보처리방침

이 방침은 사용자가 자신의 Mac에서 운영하는 개인용 COCO에 적용됩니다. COCO는 연결한 서비스의 권한과 사용자의 요청 범위 안에서 정보를 처리합니다.

1. 접근하는 정보와 목적

Google 계정을 연결하면 연결 계정의 식별 정보, 사용자가 요청한 이메일의 제목·발신자·수신자·날짜·본문·첨부 관련 정보 및 초안에 접근할 수 있습니다. 이 정보는 요청한 메일 검색, 내용 확인, 업무 자료 정리, 초안 작성과 승인된 발송에 사용합니다.

연결한 일정·할 일·업무 메시지 서비스에서는 요청에 필요한 일정, 할 일, 대화와 처리 상태를 사용합니다. 볼 수 있거나 수정할 수 있다는 이유만으로 타인의 일정을 본인 일정으로 취급하지 않습니다.

2. AI 처리와 개인 업무 기록

사용자가 AI 분석·요약·초안 작성을 요청하면 필요한 관련 내용이 사용자가 선택한 AI 서비스로 전달될 수 있습니다. COCO의 작업 과정에는 OpenAI 또는 Anthropic 기반 도구 등이 사용될 수 있으며, 해당 서비스의 계정 및 데이터 처리 설정이 적용됩니다.

업무 연속성, 결과 확인과 같은 사용자의 기능을 제공하기 위해 작업 결과, 출처와 검증 기록을 개인 작업 기록으로 보관할 수 있습니다. COCO는 Google 계정 데이터를 광고, 데이터 판매, 신용 평가 또는 범용 모델 훈련용 데이터셋 제작에 사용하지 않습니다.

3. 저장과 보호

계정 인증 정보는 macOS Keychain에 저장합니다. 요청 처리에 필요한 실행 상태와 기록은 사용자 기기에 저장하고, 사용자가 선택한 문서·프로젝트 폴더에 결과물을 저장합니다. 사용자가 Dropbox 같은 동기화 폴더를 선택한 경우 해당 저장소의 동기화 정책이 적용됩니다.

COCO 자체의 실행 코드에는 업무 기록의 일괄 자동 삭제 기간을 설정하지 않습니다. 기록은 사용자가 지정한 보관 목적과 삭제 요청에 따라 관리하며, 서비스의 원본 계정 자료는 별도로 유지됩니다.

4. 제공과 전송

Google 데이터의 이용과 다른 서비스로의 전달은 사용자에게 제공하는 요청 기능에 필요한 범위 및 사용자의 동의로 제한합니다. COCO는 광고 플랫폼이나 데이터 중개업자에게 계정 데이터를 판매하거나 제공하지 않습니다. 이 안내 페이지에는 계정 데이터가 포함되지 않습니다.

공개 안내 페이지를 제공하는 호스팅 서비스에는 접속 기록이 남을 수 있으며, 사이트 방문 통계를 위해 Google Analytics가 사용될 수 있습니다. 이메일·대화 본문이나 인증 토큰을 웹페이지 방문 통계로 전송하지 않습니다.

5. 연결 해제와 삭제

사용자는 Google 계정의 서드 파티 연결 관리에서 COCO의 접근 권한을 철회할 수 있습니다. 다른 연결 서비스도 해당 서비스의 앱·연결 관리에서 철회할 수 있습니다.

연결 철회는 해당 서비스의 새로운 접근을 차단하며, 이미 사용자 기기에 저장된 업무 기록을 자동으로 삭제하지는 않습니다. 로컬 인증 정보·작업 기록·산출물의 삭제는 운영자 본인이 COCO에 요청하여 대상과 범위를 확인한 뒤 처리할 수 있습니다.

6. 운영자와 문의

COCO는 개인 운영자의 자기 계정 관리용 도구입니다. 연결 관련 문의는 Google 인증 화면에 표시되는 사용자 지원 이메일을 이용할 수 있습니다. 이 페이지에서 별도의 문의 양식이나 추가 개인정보를 수집하지 않습니다.

7. 정책 변경

접근 정보나 이용 목적이 바뀌면 이 방침을 갱신하며, 필요한 경우 변경된 이용에 앞서 사용자 동의를 받습니다.

COCO의 Google 데이터 이용에는 Google API 서비스 사용자 데이터 정책과 Limited Use 요건이 적용됩니다.
