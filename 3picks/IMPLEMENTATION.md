## 상품 데이터 계약

- 상품마스터와 `assets/products-data.js`의 원본 입력은 110개이며 표준 상품 이미지는 제품당 3장씩 330장이다. 원본 데이터와 이미지는 삭제하지 않는다.
- 사이트 운영 집합은 10개 카테고리별 `rank 1~10`, 총 100개다. 카탈로그는 이 100개를 `visibility`와 무관하게 카테고리마다 10개씩 모두 표시한다.
- 맞춤 추천은 같은 100개 안에서 정확 조건을 먼저 적용한다. 결과가 3안 미만이면 제작 가능·가격·공직자 1인 5만 원 조건은 유지하고, MOQ·납기·인쇄·제외 품목을 상담 확인 후보로 단계적으로 넓혀 빈 결과를 만들지 않는다.
- 공통 카테고리 순서는 `텀블러 → 에코백 → 볼펜 → 우산 → 티셔츠·단체복 → 수건·타올 → 머그컵 → 보조배터리 → 노트·다이어리 → 보온보냉·런치백`이며 수건·타올은 06번이다.

## 구현 판단

- 히어로는 기존 보조배터리를 티셔츠로 교체한 가로형 그래피티 일러스트를 사용한다. 데스크톱에서는 카피를 왼쪽 44%에 오버레이하고, 900px 이하에서는 키비주얼을 먼저 보여준 뒤 카피를 잇는다.
- 600px 이하의 키비주얼은 공통 레일 거터를 벗어나 `100vw`를 채운다. 원본 캔버스의 투명한 왼쪽 영역이 아니라 실제 오브젝트 경계 983px을 화면 폭에 맞추고, 가시 영역 중심점 x=1148.5px을 화면 중심에 고정한다.
- 히어로 종이 바탕은 CSS 혼합으로 보정하지 않고 알파 WebP에서 제거한다. 페이지의 실제 `#F5F0E4`가 그림 사이로 직접 보이므로 이미지 사각 경계가 생기지 않는다.
- 히어로 직후의 대형 숫자 카드 스트립은 삭제 상태를 유지한다. 대신 `100개 대표 상품·더 넓은 상품 소싱·맞춤 제작·견적과 납기 안내`를 낮은 4칸 신뢰 바로 배치한다.
- 추천 설문의 섹션 헤드는 결과 약속(`우리에게 딱 맞는 굿즈는?`), 검은 패널은 조작 안내(`맞춤 추천 입력`), 질문 영역은 실제 질문으로 역할을 분리한다. 첫 화면에서 의문사 `어떤`은 `어떤 행사를 준비하고 계신가요?` 한 곳에만 둔다.
- 총예산 입력은 `원` 대신 `만원` 단위를 사용한다. 사용자가 `100`을 입력하면 상태에는 `1,000,000원`으로 저장해 기존 추천 필터·1인당 예산·결과 문구 계산을 그대로 유지한다.
- 추천 카테고리는 조건을 통과한 대표 상품이 1개 이상이면 결과에 포함한다. 비교 상품 2개가 모두 있어야만 카테고리를 통과시키던 기존 조건은 저예산에서 전체 결과를 숨기므로 제거하고, 부족한 비교 상품은 사실대로 덜 보여준다.
- 이전 세션에 `100`처럼 만원 표시값이 저장된 경우에는 복원·추천 직전에 `1,000,000원`으로 보정한다. 10,000 이상의 기존 원 단위 저장값은 그대로 유지한다.
- 검은 패널 제목은 행사별 조건부 질문으로 7~8단계가 달라지는 점을 반영해 고정 숫자 대신 `맞춤 추천 입력`으로 표시한다.
- 마스터의 `전체마스터`는 헤더 포함 111행이며 실제 상품은 110개다. 이 원본과 표준 이미지 330장은 보존하고 사이트만 rank 기준 100개로 제한한다.
- 상품 카드의 3색은 색상을 고르는 데 도움을 주는 이미지 예시다. 모든 카드에 `실제 제작 가능 색상은 상담 후 확정됩니다`를 고정 표기한다.
- 카카오톡 상담 CTA는 사용자가 제공한 `https://open.kakao.com/me/3PICK`을 `config.js` 한 곳에서 관리하고 새 창으로 연다. 주소가 비어 있을 때만 기존 담당자 연락처 안내 대화상자로 대체한다.
- 헤더와 하단 상담 전환은 서로 다른 2버튼 조합을 폐기하고 `맞춤추천·카카오톡 상담하기·이메일문의`의 동일한 3버튼 조합으로 통일한다. 추천은 `#recommend`, 카카오는 기존 `data-consult`, 이메일은 `config.js`의 담당자 이메일로 연결한다.
- 정확 조건 뒤 3안이 남지 않으면 상담 조정 가능한 후보를 보충하고, 완화된 MOQ·납기·인쇄·제외 품목을 각 구성에 명시한다. 버튼 선택만으로 끝나는 모든 경로는 반드시 3안을 반환한다.
- 마스터에 트렌드 태그 전용 열이 없어 `상품성격·특징/비고·카테고리` 텍스트에서 12개 태그를 보수적으로 파생한다. 추천 이유에는 이 파생 사실을 노출하지 않고 행사·예산·납기·로고 조건만 설명한다.
- 가격·MOQ·납기를 숫자로 해석할 수 없는 상품은 전체 카탈로그에는 표시하되 자동 추천에서는 제외한다. 하드 필터를 통과했다고 과장하지 않기 위한 보수적 처리다.
- 새로고침 시 앵커 해시보다 저장된 세로 위치를 우선하고, 복원 직전에 URL 해시를 제거해 설문 위치로 다시 끌려가지 않게 한다.
- 추천이 끝나면 설문 답변과 3개 추천 그룹의 상품 ID를 탭 세션에 저장하고, 새로고침 탐색에서 같은 순서로 복원한다. `조건 다시 입력하기`를 누르면 저장 결과도 함께 지운다.
- 모든 상품 카드의 우상단 하트는 동일 상품 ID로 동기화하고 최대 12개를 로컬 저장한다. 담을 때 합계 포함이 기본이며 체크 해제는 보관만 유지하고 계산·PDF·상담 요약에서 제외한다.
- 미니 견적은 브라우저 하단에 길고 낮은 가로 프레임으로 고정해 본문을 계속 볼 수 있게 한다. 공통 수량은 100개 기본·20개 단위이며 상품별 MOQ보다 작으면 적용 수량만 MOQ로 올린다.
- 상품 금액은 현재 기준 단가×적용 수량의 참고 합계다. 인쇄·배송·부가세는 구조화된 값이 아니므로 숫자 합계에 넣지 않고 상담 확인 문구로 남긴다.
- `PDF 미니 견적서`는 A4 인쇄 전용 새 창을 만들고 브라우저의 인쇄·PDF 저장 기능을 호출한다. 견적 바 자체는 팝업으로 전환하지 않는다.
- GNB 가장 오른쪽의 `멤버 소개`는 FAQ 다음의 `#about`으로 이동한다. 백선미 이사의 실제 경력과 소개를 텍스트로 제공하고, 두 번째 멤버는 가짜 이력 없이 준비 중 더미로 둔다.
- 푸터에는 교체용 임시값 `사업자등록번호 000-00-00000`, `통신판매업 신고번호 제2026-서울강남-0000호`를 두며 실제 번호를 받으면 두 줄만 바꾼다.
