# 3PICKS 추천·상품 데이터 전수조사

검사일: 2026-08-11

## 판정

- 상품마스터와 브라우저 입력 데이터 110개는 보존한다. 사이트와 추천은 그중 10개 카테고리의 rank 1~10, 총 100개만 운영 집합으로 사용한다.
- 카탈로그는 운영 상품 100개를 `visibility`와 무관하게 모두 표시한다. 추천은 같은 100개 안에서 정확 조건을 우선하고, 3안 미만이면 상담 조정 가능한 후보로 보충한다.
- 1인당 10만 원 조건에서 5천 원대 수건 단품이 나온 원인은 예산을 목표값이 아니라 상한선으로만 사용한 추천 알고리즘이다.
- 현 상품마스터에는 수건 세트나 10만 원대 키트 완제품이 없으므로, 고예산을 맞추려면 서로 다른 카테고리의 1~3종 상품을 묶어야 한다.

## 교정한 추천 계약

1. 카테고리별 rank 1~10인 100개 운영 집합 밖의 상품을 먼저 제외한다.
2. 정확 필터로 노출·제작 가능·MOQ·납기·인쇄·제외 품목·공직자 5만 원 조건을 지킨다.
3. 정확 결과가 3안 미만이면 제작 가능·가격·공직자 상한은 유지하고 상담 후보를 보충한다.
4. 입력 수량과 상품별 MOQ를 반영한 총액으로 서로 다른 카테고리의 1~3종 조합을 계산한다.
5. 총 가예산과 절대 차이가 가장 작은 조합부터 3안을 보여주고 상담 확인 항목을 밝힌다.
6. 예산이 없으면 행사·태그·계절·인기도·품질순위로 대표 3안을 반드시 보여준다.

- 2026-08-10 원본 상품마스터 110행과 브라우저 입력 110개의 핵심 필드 전수 대조 통과.
- 2026-08-11 운영 집합 100개·카테고리별 10개·rank 1~10·중복 0개·수건 06번 검사 통과.
- 행사 8종 × 인원 3구간 × 인당 예산 4구간, 총 96개 시나리오 통과.
- 객관식·조건부 질문·태그 298조합·제외 품목 1,024조합·수치 경계, 총 5,786개 시나리오 통과.
- 기존 빈 결과인 `1명·당일`, `전 품목 제외`, `1명·당일·공직자 포함`도 각각 3안 반환.
- 100명·총예산 1,000만 원에서 첫 구성가는 인당 99,600원, 총 9,960,000원이며 가예산 40,000원이 남는다.
- 예산 모름은 대표 3개를 반환하고, 공직자 포함 조건은 모든 구성가가 인당 5만 원 이하다.
- 최종 통합본의 데스크톱·모바일 가로 넘침과 콘솔 오류 검사는 대기 상태다.

## 데이터 한계

- 운영 상품의 런타임 단가는 모두 100개 주문 기준 단일 단가다. 마스터가 요구하는 50·100·300·500개 구간 단가는 아직 없다.
- 추천 총액은 입력 수량과 MOQ를 반영한 상품 가예산이며 인쇄비·포장비·배송비·부가세는 포함하지 않는다.
- 실제 금액은 재고·수량별 단가·인쇄·포장·배송 조건에 따라 달라질 수 있음을 결과 마지막에 안내한다.
- 실제 주문 수량별 단가와 제작 가능 색상은 상담에서 재확인해야 한다.
