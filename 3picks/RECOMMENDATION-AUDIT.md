# 3PICKS 추천·상품 데이터 전수조사

검사일: 2026-08-10

## 판정

- 상품 DB가 망가진 것은 아니다. 상품마스터 110행과 런타임 110개를 번호별로 대조했으며 카테고리·상품명·노출구분·100개 기준 단가 불일치는 0건이다.
- 1인당 10만 원 조건에서 5천 원대 수건 단품이 나온 원인은 예산을 목표값이 아니라 상한선으로만 사용한 추천 알고리즘이다.
- 현 상품마스터에는 수건 세트나 10만 원대 키트 완제품이 없으므로, 고예산을 맞추려면 서로 다른 카테고리의 1~3종 상품을 묶어야 한다.

## 교정한 추천 계약

1. 하드 필터로 노출·제작 가능·MOQ·납기·인쇄·제외 품목·공직자 5만 원 조건을 지킨다.
2. 예산이 있으면 서로 다른 카테고리의 1~3종 상품 조합을 모두 계산한다.
3. 목표 인당 예산과 절대 차이가 가장 작은 조합을 첫 번째로 내고 상위 3개 구성을 보여준다.
4. 구성별로 `예산 N원 남음`, `예산 N원 부족`, `예산에 맞음`을 표시한다.
5. 예산이 없으면 행사 매핑·태그·계절·인기도·품질순위로 서로 다른 카테고리의 대표 상품 3개를 보여준다.

## 회귀 검증

- 상품 데이터 전수 대조 통과.
- 행사 8종 × 인원 3구간 × 인당 예산 4구간, 총 96개 시나리오 통과.
- 100명·총예산 1,000만 원 회귀 조건에서 첫 구성가는 99,600원이며 인당 400원이 남는다.
- 예산 모름은 대표 3개를 반환하고, 공직자 포함 조건은 모든 구성가가 인당 5만 원 이하다.
- 데스크톱과 모바일 브라우저에서 가로 넘침 0, 콘솔 경고·오류 0을 확인했다.

## 데이터 한계

- 런타임 단가는 모두 100개 주문 기준 단일 단가다. 마스터가 요구하는 50·100·300·500개 구간 단가는 아직 없다.
- 추천 구성가는 상품 단가의 합계이며 인쇄비·포장비·배송비·부가세는 포함하지 않는다.
- 실제 주문 수량별 단가와 제작 가능 색상은 상담에서 재확인해야 한다.
