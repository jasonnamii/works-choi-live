홈페이지 관리 화면

이 화면은 연습장이라고 생각하면 됩니다. 여기서 무엇을 고쳐도 실제 홈페이지는 바로 바뀌지 않아요. 맨 아래의 홈페이지에 반영하기 버튼을 눌러야만 진짜 홈페이지가 바뀝니다. 그 전까지는 마음껏 눌러 보고, 바꿔 보고, 미리보기로 확인해도 안전합니다.

  • 걱정하지 않아도 되는 이유여기서 고치는 내용은 이 컴퓨터 화면 안에만 머뭅니다. 실수로 무엇을 누르거나 바꿔도 홈페이지는 그대로예요.
  • 홈페이지가 바뀌는 순간딱 하나, 「홈페이지에 반영하기」 버튼을 눌렀을 때뿐입니다. 누르면 1~10분 뒤에 바뀝니다.
  • 고객 미니 견적홈페이지 견적함의 수량 계산과 「비우기」는 고객 화면에서 바로 동작합니다. 상품·추천 설정은 이 운영 콘솔에서 관리하고, 담은 목록 자체는 고객의 브라우저에만 저장됩니다.
  • 이메일 문의 담당자홈페이지의 이메일 문의 레이어에 보이는 두 담당자는 config.js에서 바꿉니다. 이 운영 콘솔의 상품·추천 설정과는 별개입니다.
  • 잘못 고쳤을 때맨 아래 「고친 내용 모두 취소」를 누르면 이 화면이 처음 상태로 돌아옵니다. 홈페이지는 사라지지도, 바뀌지도 않습니다.
01 · Connection

처음 한 번, 홈페이지와 연결

홈페이지 파일이 보관된 곳(깃허브라는 서비스)과 이 화면을 잇는 단계입니다. 아래 네 칸은 설치를 도와준 담당자가 알려준 값을 그대로 붙여 넣으면 됩니다. 한 번 연결해 두면 다음부터는 건드릴 일이 없습니다.

비밀 열쇠는 현재 탭을 닫으면 지워집니다.

아직 연결을 확인하지 않았습니다.

비밀 열쇠(토큰)는 깃허브 사이트에서 발급받습니다. 어렵게 느껴지면 설치 담당자에게 부탁하세요. 입력한 열쇠는 현재 탭에만 잠시 저장되며 탭을 닫으면 지워집니다.
  1. 깃허브(GitHub) 우측 상단 프로필 → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access는 이 홈페이지 보관함 하나만 선택합니다.
  3. Permissions에서 Contents만 Read and write로 켭니다. 다른 권한은 필요 없습니다.
  4. 만든 열쇠를 위 칸에 붙여 넣고 연결 확인을 누릅니다. 자세한 순서는 함께 전달된 설치 가이드에 있습니다.
02 · How it works

맞춤 추천이 만들어지는 원리

고객이 홈페이지에서 설문을 마치면 아래 다섯 단계를 거쳐 추천 3안이 만들어집니다. 각 단계를 이 화면의 어느 부분에서 조정하는지도 함께 적어 두었습니다.

  1. STEP 1

    운영 상품 확정

    전체 상품 중 카테고리별 순위 1~10위, 총 100개가 홈페이지에 진열되고 추천 대상이 됩니다.

    편집: 상품 운영 → 순위

  2. STEP 2

    조건 필터

    자동 추천 대상 여부, 인원 대비 최소 주문 수량, 납기, 인쇄 가능 여부, 제외 품목, 공직자 5만 원 기준으로 후보를 거릅니다.

    편집: 상품 운영 → 추천 여부

  3. STEP 3

    점수 매기기

    남은 후보마다 태그 일치, 인기도, 품질 순위, 행사 관련성, 계절 가점을 합산합니다.

    편집: 가중치 · 행사 매핑

  4. STEP 4

    조합 만들기

    서로 다른 카테고리 1~3종을 묶는 모든 조합을 만듭니다. 같은 카테고리 중복은 허용하지 않습니다.

    확인: 미리보기에서 교체

  5. STEP 5

    예산 맞춤 3안

    총예산과 예상 총액의 차이가 가장 작은 순으로 3안을 고릅니다. 3안이 안 나오면 상담 확인 후보로 보충합니다.

    기준: 예산은 목표값

  • 자동 순위 조정워크샵(강의·연수형)은 볼펜을 3순위로 올립니다 · 워크샵(야외·단합형)이 6~8월이면 보온보냉·런치백을 4순위로 올립니다 · 전시(등록 참가자 키트)는 티셔츠·단체복을 3순위로 올립니다 · 명절 선물이 12~1월이면 노트·다이어리를 1순위로 올립니다.
  • 계절 가점우산 5~7월 · 노트·다이어리 10~12월 · 티셔츠·단체복 4·5·9·10월 · 보온보냉·런치백 4~7월에 계절 점수가 붙습니다.
  • 공직자 기준받는 분에 공직자·교직원·언론인이 포함되면 1인 구성가 5만 원 초과 상품과 조합을 제외합니다.
  • 3안 보장조건 그대로는 3안이 안 나올 때, 수량·납기·인쇄를 상담으로 조정할 수 있는 후보를 더해 항상 3안을 채우고 상담 확인 항목을 함께 표시합니다.
  • 정렬 순서예산 차이가 작은 조합 → 예산 안에 드는 조합 → 점수 높은 조합 → 구성 품목이 많은 조합 순으로 우선합니다.

05 · Preview

06 · Catalog curation

카테고리별 상품 운영

위·아래 버튼으로 순위를 바꿉니다. 각 카테고리의 1~10위, 총 100개는 지금 홈페이지에 전부 진열되어 있습니다. 그 아래 대기 상품은 순위를 10위 안으로 올리면 자리를 맞바꿔 진열됩니다. 상품을 펼치면 이름·가격·수량·납기·인쇄 방식·사진까지 전부 고칠 수 있고, 「자동 추천에 나감」 버튼을 끄면 홈페이지 진열은 그대로 두고 자동 추천에서만 빠져 상담 때 제안하는 상품이 됩니다. 「숨김」을 누르면 홈페이지에서 잠시 내려가고 아래 순위 상품이 자동으로 올라와 자리를 채웁니다. 당분간 안 쓸 상품은 「보관」으로 보관함에 옮겨 두세요 — 지우는 기능은 없으니 무엇도 사라지지 않습니다. 여기서 바꾼 것도 아직 홈페이지에 올라간 상태는 아니에요.

새 상품도 여기서 바로 만들 수 있습니다. 사진과 정보를 채워 「등록」을 누르면 아래 목록에 들어가고, 홈페이지에는 「홈페이지에 반영하기」를 눌러야 올라갑니다.

    07 · Review & publish

    바뀐 내용 확인하고 홈페이지에 올리기

    지금까지 이 화면에서 고친 내용이 아래에 목록으로 모입니다. 목록을 읽어 보고 맞으면 「홈페이지에 반영하기」를 누르세요. 실제 홈페이지를 바꾸는 버튼은 이것 하나뿐입니다.

    • 홈페이지에 반영하기여기서 고친 내용을 실제 홈페이지에 올립니다. 새로 올린 상품 사진이 있으면 사진 파일부터 먼저 올라가고 설정이 마지막에 올라갑니다. 1~10분 뒤부터 모든 방문자에게 새 내용이 보입니다.
    • 백업 파일 받기고친 내용을 파일 하나로 내 컴퓨터에 저장해 둡니다. 눌러도 홈페이지에는 아무 일도 일어나지 않아요. 꼭 받아야 하는 것도 아닙니다.
    • 직전 정상본 불러오기마지막 반영 직전의 홈페이지 설정을 이 화면에 초안으로 불러옵니다. 확인 뒤 「홈페이지에 반영하기」를 눌러야 실제 복구됩니다.
    • 고친 내용 모두 취소이 화면에서 고친 것만 지우고 처음 상태로 되돌립니다. 홈페이지는 그대로 있습니다. 사라지지 않아요.

      「홈페이지에 반영하기」를 누르면 홈페이지가 새 내용으로 갈아입는 데 1~2분, 이미 접속해 있던 방문자 화면까지 바뀌는 데 길게는 10분이 걸립니다. 급하지 않다면 미리보기로 충분히 확인한 뒤 한 번에 반영하는 편이 좋습니다.
